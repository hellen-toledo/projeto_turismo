### Projeto Turísmo 

Este projeto consiste no desenvolvimento de uma plataforma digital voltada para a promoção do turismo e da cultura da região do Norte Goiano. O sistema oferece uma experiência completa para turistas e uma área de gestão administrativa para controle de informações.

#### Funcionalidades Principais:

- Visualização Detalhada: Acesso a descrições históricas e pontos turísticos das cidades.
- Galeria de Mídia: Sistema para visualização e gerenciamento de fotos e guias locais.
- Calendário de Eventos: Visualização de datas e eventos importantes da região.
- Painel Administrativo: Área exclusiva para gerentes realizarem o cadastro, edição e exclusão de informações (CRUD).
  
#### Tecnologias Utilizadas

O projeto utiliza tecnologias modernas de desenvolvimento para garantir performance e segurança:

- Back-End: PHP com o framework Laravel.
- Banco de Dados: Modelagem via Eloquent ORM.
- Autenticação: Gerenciamento de tokens via Laravel Sanctum.
- Front-End: React com TypeScript e Vite.
- Estilização: TailwindCSS para garantir design responsivo.
- Gestão de Estado: Configuração com Zustand ou Redux.

#### Cronograma de Desenvolvimento

O desenvolvimento está dividido em cinco etapas estratégicas:

- Fase 1: Planejamento, Design de Interface (UX/UI) e mapeamento de jornadas.
- Fase 2: Fundação do Back-End, modelagem de dados e criação da API de autenticação.
- Fase 3: Desenvolvimento do Front-End (Núcleo) e integração dos cards interativos.
- Fase 4: Implementação das funcionalidades administrativas e gestão de mídia.
- Fase 5: Refinamento de segurança, acessibilidade (WAI-ARIA) e otimização de desempenho.



Nota de Organização: Este repositório segue a estratégia Git Flow para garantir a integridade do código em todas as fases de produção.
